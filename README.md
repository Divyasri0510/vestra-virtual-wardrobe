# VESTRA

VESTRA is a responsive virtual wardrobe website for organizing clothes, creating outfits, and discovering personalized style combinations.

## Features

- Responsive fashion-focused HTML5 and CSS3 interface
- Filterable wardrobe categories
- Selectable clothing cards
- Outfit Planner that updates from selected pieces
- Generate Outfit button with style recommendations
- Working navigation, Login, and Add item controls
- Vanilla JavaScript with no build step

## Run locally

Open `index.html` directly in a browser, or start a local server:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive styling
- `app.js` - wardrobe filtering and outfit interactions
- `README.md` - project documentation
